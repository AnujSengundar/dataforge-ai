# Feature Scope

## MVP

The MVP focuses on a reliable file-to-insight workflow.

- Upload CSV.
- Preview dataset.
- Infer schema from uploaded data.
- Generate a data profile.
- Store dataset metadata.
- Load raw data into PostgreSQL.
- Show basic summary insights.

## Version 2

Version 2 expands the product from basic ingestion and profiling into a more complete analytics workspace.

- Upload Excel files.
- Manage multiple datasets per user or workspace.
- Track dataset versions.
- Configure column types and business labels.
- Validate data quality rules.
- Create reusable cleaning presets.
- Generate curated tables from raw staging tables.
- Add dashboard-ready aggregate tables.
- Provide exportable data dictionaries.

## Advanced and AI Features

Advanced features turn the platform into an AI-assisted analytics studio.

- Auto data cleaning.
- Star schema generation.
- Power BI-ready semantic model.
- ML forecasting.
- RAG over dataset metadata.
- Ollama-powered chat.
- MCP tools.
- Executive report export.

## Not in Scope for Now

The following items are intentionally deferred to keep the first implementation focused:

- Real-time streaming ingestion.
- Enterprise SSO.
- Multi-tenant billing.
- Paid third-party data connectors.
- Complex role-based access control.
- Production-grade distributed processing.
- Automated web scraping.
- Fully automated BI dashboard publishing.
- External managed AI services.
- Mobile application support.
