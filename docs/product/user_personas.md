# User Personas

## Freelancer Data Analyst

| Area | Description |
|---|---|
| Pain point | Client files are inconsistent, undocumented, and time-consuming to prepare before analysis can begin. |
| Goal | Deliver reliable insights, dashboards, and reports faster while maintaining professional quality. |
| How DataForge AI Studio helps | Automates profiling, schema inference, raw loading, metadata capture, and first-pass insights so the freelancer can focus on analysis and client recommendations. |

## Small Business Owner

| Area | Description |
|---|---|
| Pain point | Business data is spread across spreadsheets and exports, making it difficult to understand performance clearly. |
| Goal | Get simple, trustworthy insights without hiring a dedicated data team. |
| How DataForge AI Studio helps | Converts uploaded files into structured data, highlights summary metrics, and prepares data for reporting tools such as Power BI. |

## Startup Founder

| Area | Description |
|---|---|
| Pain point | Early-stage teams need visibility into operations but often lack formal data infrastructure. |
| Goal | Quickly turn product, sales, marketing, or finance exports into actionable business intelligence. |
| How DataForge AI Studio helps | Provides a lightweight data platform that supports file ingestion, profiling, warehouse loading, and AI-assisted analysis. |

## Recruiter or Hiring Manager Evaluating the Portfolio

| Area | Description |
|---|---|
| Pain point | Portfolio projects often demonstrate isolated tools but not end-to-end product thinking or production-oriented architecture. |
| Goal | Evaluate whether the candidate can design, build, and communicate a realistic data platform. |
| How DataForge AI Studio helps | Demonstrates practical experience across data engineering, analytics engineering, AI engineering, ML, APIs, warehousing, dashboarding, Docker, and architecture documentation. |

## Student or Job Seeker

| Area | Description |
|---|---|
| Pain point | It is difficult to build a project that feels realistic, differentiated, and aligned with modern data roles. |
| Goal | Learn and showcase end-to-end data platform skills through a portfolio-grade product. |
| How DataForge AI Studio helps | Provides a clear product surface for practicing ingestion, profiling, SQL modeling, API design, dashboarding, ML, AI chat, and report generation. |
