# Tech Stack

| Layer | Tool | Why Chosen | Portfolio Value |
|---|---|---|---|
| Programming language | Python | Strong ecosystem for APIs, ETL, data profiling, ML, and AI workflows. | Demonstrates practical data engineering and AI engineering skills. |
| API backend | FastAPI | High-performance Python framework with strong typing, OpenAPI support, and clean service boundaries. | Shows modern API design and production-oriented backend development. |
| Metadata database | PostgreSQL | Reliable relational database for dataset metadata, lineage, profiles, and processing state. | Demonstrates relational modeling and operational data storage. |
| Warehouse | PostgreSQL | Practical first warehouse layer for staging, curated models, and analytical queries. | Shows SQL modeling, warehouse thinking, and cost-aware architecture. |
| ORM | SQLAlchemy | Mature Python ORM and SQL toolkit for database access. | Demonstrates maintainable database integration patterns. |
| Migrations | Alembic | Standard migration tool for SQLAlchemy-based projects. | Shows schema versioning and production database discipline. |
| Data processing | Pandas | Efficient tool for CSV/Excel inspection, profiling, and transformation in the MVP. | Demonstrates hands-on data preparation and analysis workflows. |
| Data validation | Great Expectations or Pandera | Supports data quality checks, schema validation, and repeatable validation rules. | Shows analytics engineering and data quality practice. |
| BI layer | Power BI | Widely used business intelligence tool for dashboards and executive reporting. | Demonstrates business-facing analytics and reporting delivery. |
| Local AI | Ollama | Enables local-first LLM features without depending on paid external AI services. | Shows AI engineering with privacy-aware, self-hosted model workflows. |
| Vector storage | ChromaDB or Qdrant | Supports retrieval over metadata, profiles, documentation, and semantic context. | Demonstrates RAG architecture and vector-search integration. |
| Agent/tool interface | MCP | Exposes platform capabilities to AI tools through a structured protocol. | Signals awareness of emerging AI integration standards. |
| Containerization | Docker | Packages services consistently for local development and repeatable demos. | Demonstrates deployable platform thinking. |
| CI/CD | GitHub Actions | Automates tests, linting, and quality checks as the project grows. | Shows engineering maturity and professional workflow habits. |
| Frontend | Next.js or React | Provides a modern interface for file upload, profiling views, insights, and chat. | Demonstrates full-stack product delivery and SaaS-style UI thinking. |
